About AXON Technical Society

AXON is an official student-led technical society operating under the Institute of Machine Learning, Artificial Intelligence & Cyber Security (IMAC) at UET Lahore.

Our Official Motto

"Learn by Building, Grow by Connecting."

Established to bridge regular academic study with real-world technical execution, AXON provides a collaborative platform where students transform core computational concepts into working applications, active project repositories, and industry-ready skills.

Three Pillars of Focus

1. Web & Software

Responsive interface architecture, clean frontend design, and scalable full-stack development using modern web technologies to build production-grade web applications.

2. Programming & AI

Building a strong foundation in Python, algorithmic thinking, and core data structures to prepare students for applied machine learning and data science.

3. Industry Engagement

Connecting students with departmental initiatives, faculty-led projects, tech companies, and software houses through technical workshops and speaker sessions.

Our Specialized Wings

Web Development Wing AI & Machine Learning Wing Cyber Security Wing Competitive Programming Wing
